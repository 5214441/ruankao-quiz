二、上传方法
1. 解压本压缩包。
2. 打开 GitHub 仓库 5214441/ruankao-quiz。
3. 在仓库根目录点击 Add file → Upload files。
4. 把解压后的 index.html、assets 文件夹、apps 文件夹一起拖入上传区域。
5. Commit message 填：新增BTC短线行情雷达 V1.1
6. 保持 Commit directly to the main branch。
7. 点击 Commit changes。
8. 等待 GitHub Actions 自动部署完成。

四、安全设计
- 不需要币安API密钥
- 不连接账户
- 不读取余额或仓位
- 不自动下单
- 自定义提醒、快照和复盘记录仅保存在当前浏览器
- 页面规则化指标只用于行情学习、监测和复盘

五、首次打开
- 浏览器可能会询问“通知”权限，只有启用浏览器通知时才需要允许。
- 手机语音播报通常需要先点击一次“测试语音”，之后自动播报才会生效。
- 若当地网络无法访问公开行情接口，页面会明确显示“接口暂不可用”，不会伪造行情数据。
